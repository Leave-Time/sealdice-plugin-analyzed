# 检定统计与成就

统计 COC 检定成功率与各类结果次数，支持其他插件接入成就登记、解锁和查询。

## 安装

在海豹 WebUI 扩展管理中导入本 `.sealpack` 文件，确认 `analyzed` 已启用。

## 使用

- `.analyzed`：查看检定统计。
- `.achievements list [页码]`：查看成就列表。
- `.achievements info 名称`：查询成就详情。

成就由其他插件登记，未接入成就插件时列表为空。

成就默认以文字显示；图片模式需在扩展配置中选择“图片”并填写“成就渲染API”地址。

文字默认不显示 ID，解锁日期精确到天；开启 `DEBUG` 可显示 ID。将 `成就文字发送方式` 设为“合并转发”时，需要填写 QQ 协议端的 `OneBot HTTP API` 根地址（例如 `http://127.0.0.1:3000`）和可选 `OneBot HTTP Token`。地址对应当前骰子账号，失败时回退普通消息。

## 自定义文案配置

安装后，在海豹 WebUI 打开 **自定义文案 → COC → 判定-常规**，在对应文案末尾追加脚本并保存。不要覆盖原有内容，每项只追加一次；变量会随文案执行自动累加。

### 普通结果

| 文案项 | 追加脚本 |
| --- | --- |
| `判定_普通成功` | `{%if 1 {$m普通成功=$m普通成功+1}%}` |
| `判定_困难成功` | `{%if 1 {$m困难成功=$m困难成功+1}%}` |
| `判定_极难成功` | `{%if 1 {$m极难成功=$m极难成功+1}%}` |
| `判定_大成功` | `{%if 1 {$m大成功=$m大成功+1}%}` |
| `判定_失败` | `{%if 1 {$m失败=$m失败+1}%}` |
| `判定_大失败` | `{%if 1 {$m大失败=$m大失败+1}%}` |

文案名称以当前海豹版本显示为准。

### 必须困难 / 极难 / 大成功：失败文案

在 `判定*必须*困难_失败`、`判定*必须*极难_失败` 和 `判定*必须*大成功_失败` 中分别追加以下脚本，区分大失败与普通失败：

```text
{%
if $t附加判定结果=='(大失败)'
{
    $m大失败=$m大失败+1
}
else
{
    $m失败=$m失败+1
}
%}
```

### 必须困难：成功文案

在 `判定*必须*困难_成功` 中追加：

```text
{%
if $t附加判定结果=='(大成功)'
{
    $m大成功=$m大成功+1
}
else
{
    $m困难成功=$m困难成功+1
}
%}
```

### 必须极难：成功文案

在 `判定*必须*极难_成功` 中追加：

```text
{%
if $t附加判定结果=='(大成功)'
{
    $m大成功=$m大成功+1
}
else
{
    $m极难成功=$m极难成功+1
}
%}
```

### 必须大成功：成功文案

在 `判定*必须*大成功_成功` 中追加，无需区分成功等级：

```text
{%if 1 {$m大成功=$m大成功+1}%}
```

如修改了附加判定文本，请同步调整条件。配置完成后执行几次 `.ra` 或 `.rc`，再用 `.analyzed` 确认次数增加；历史检定不会补录。
